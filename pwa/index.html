Keep Rainette one tap away

iPhone: tap Share in Safari, then Add to Home Screen.

Android: open the browser menu, then Install app.

On iPhone the Home Screen copy gets its own storage, so it starts unpaired even though Safari is paired. Make a second pairing code on your computer and pair the installed app once — after that it stays paired and you can stop using Safari.
